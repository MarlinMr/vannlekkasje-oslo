# Grønland district-heating leak diorama

Open [diorama.html](diorama.html) in a modern browser. No build step or internet connection is required to view the scene: the local 3D library is in `vendor/three.min.js`. The page needs WebGL enabled.

Drag the scene to orbit, scroll to zoom, and select **Before**, **The rupture**, or **Afterwards** to compare stages. The 3D street is an **illustration**, not a survey-accurate reconstruction. [EVENT.md](EVENT.md) contains the sourced chronology. Public deployment includes a [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) street photograph by [Helge Høifødt](https://commons.wikimedia.org/wiki/File:Gr%C3%B8nlands_torg_sett_mot_T%C3%B8yenbekken.JPG); event-photo cards link to the publishers instead of republishing their copyrighted images.
